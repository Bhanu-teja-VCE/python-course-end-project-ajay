## Problem Statement
Develop a Python facility management system to administer student residential accommodations, enforce room bed capacities, prevent double-allocations, automate first-available bed assignment, compute vacancies, and search resident records.

**CO Mapping:** CO1, CO3, CO4  |  **PO Mapping:** PO1, PO2, PO3, PO5

---

## Features
- **Comprehensive Occupancy Display:** View occupancy status and student rosters across all rooms.
- **Vacancy Calculator:** Real-time computation of vacant beds per room and gross facility vacancies.
- **Dual-Mode Allocation Engine:** Assign students to specific rooms or utilize automatic assignment to the first available room.
- **Anti-Collision Guard:** Guarantees that a student roll number cannot be allocated more than one room simultaneously.
- **Student Directory Search:** Instant student lookup by roll number displaying academic branch and assigned room number.
- **Persistent Storage:** Synchronized automatically with `hostel_data.json`.
