1. Problem Statement & Project Overview

Academic campuses, colleges, and training facilities accommodate hundreds of resident students annually. Traditional manual allocation leads to frequent double-bookings, unmonitored room vacancies, slow student query lookups, and administrative difficulties when students vacate or change rooms during semester transitions.

The Hostel Room Allocation Management System developed by Ajay provides an automated solution for residential facility managers. The system maintains capacity limits per room, prevents double allocations, offers both manual room selection and automatic first-available bed assignment, tracks real-time vacancies, and facilitates fast search by student roll number.

Dual-Mode Room Allocation

Enables direct room assignment or autonomous fallback allocation that claims the first available bed across all configured rooms.

Anti-Duplicate Allocation Guard

Global lookup ensures a student cannot be allocated more than one room simultaneously across the residential complex.

2. System Architecture & Workflow

The system is organized around a hierarchical dictionary persisted in hostel_data.json. Each room acts as an independent entity maintaining its target capacity and an active resident roster.

Core Workflow:

  1. Seed Configuration: If no existing database is found, the system seeds 5 double-occupancy rooms (101-105, capacity 2) and 3 triple-occupancy rooms (201-203, capacity 3).
  2. Allocation Verification: Verifies that the student's roll number is not already assigned to any room across the entire facility.
  3. Assignment: If manual room number is provided, verifies room existence and bed capacity. If empty input, auto-assigns the first room with available capacity.
  4. Deallocation & Search: Allows vacating a room by roll number and provides instant student location lookup.

4. Algorithmic Deep Dive & Underlying Logic

A. Global Student Uniqueness Scanner

To prevent double-booking, the helper function find_student() scans the room hierarchy: 

def find_student(data, roll):
    for room_no, room in data["rooms"].items():
        for s in room["students"]:
            if s["roll"] == roll:
                return room_no, s
    return None, None

Returning both the room number and the matched student reference allows this function to power both duplicate checking, vacating, and directory search.

B. Autonomous Fallback Allocation

When an administrator leaves the room selection blank (presses Enter), the system iterates through rooms until it discovers one with open beds: 

if not room_no:
    for r, room in data["rooms"].items():
        if len(room["students"]) < room["capacity"]:
            room_no = r
            break
    else:
        print("No vacant rooms available.")
        return

C. Dynamic Bed Vacancy Computation

Vacancies are calculated on the fly without maintaining redundant counter variables that could risk state drift: 

total = 0
for room_no, room in data["rooms"].items():
    free = room["capacity"] - len(room["students"])
    if free > 0:
        print(f"Room {room_no}: {free} bed(s) free")
        total += free
print(f"Total vacant beds: {total}")
